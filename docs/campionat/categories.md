# Categories

El mundial té tres categories. Els pilots solen pujar d'una a una altra segons els resultats.

## Les tres categories

1. **Moto3**: la categoria d'accés.
2. **Moto2**: la categoria intermèdia.
3. **MotoGP**: la categoria reina.

| Categoria | Motor |
|-----------|-------|
| Moto3 | 250 cc, un cilindre |
| Moto2 | 765 cc, tres cilindres |
| MotoGP | 1000 cc, quatre cilindres |

!!! tip "Consell"
    Les motos de MotoGP són **prototips**: no es poden comprar en una botiga.

??? info "Què vol dir cc?"
    Són els centímetres cúbics, una mesura de la cilindrada del motor.
