# Banderes

Els comissaris del circuit fan servir banderes per a avisar els pilots.

## Les més importants

- **Groga**: perill a la pista. Està prohibit avançar.
- **Vermella**: la cursa s'atura.
- **Blava**: un pilot més ràpid es disposa a doblar-te.
- **Negra**: el pilot ha d'entrar a boxes.
- **De quadres**: final de la cursa.

!!! danger "Perill"
    Si hi ha una bandera groga, els pilots han de reduir la velocitat.

??? warning "Què passa si no es respecta?"
    El pilot pot rebre una sanció, com per exemple perdre posicions.
