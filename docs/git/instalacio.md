# Instal·lació

## Instal·lar Git

En macOS es pot instal·lar amb Homebrew:

```bash
brew install git
```

Per comprovar que s'ha instal·lat:

```bash
git --version
```

## Configuració inicial

Abans del primer commit cal indicar el nom i el correu:

```bash
git config --global user.name "El meu nom"
git config --global user.email "correu@exemple.com"
```

!!! tip "Consell"
    Fes servir el mateix correu que tens a GitHub.
